# Octo 原生 IM 渠道

本模块直接接入 Octo，不依赖其他 Agent 运行时。正式部署、真实消息验收和限制记录统一见 [OCTO-STATUS](../../../OCTO-STATUS.md)。配置流程见 [OCTO-SETUP](../../../OCTO-SETUP.md)。

## 能力与配置

在原生 IM 页面选择 Agent、创建加密 Bot 连接并核验真实身份；默认保存为停用。群／子区必须有官方核验的区域与有效查询绑定；私聊使用独立 UID 和知识库许可。一个 Bot 只能有一个有效接收端。

群与子区按用户隔离会话，回复使用原生 UID @ 和完整引用。GROUP.md／THREAD.md 每轮只作为当前区域资料读取，不作为权限配置。内置 skills 仅提供渠道使用说明，不安装 shell 或任意执行工具。

“Octo 知识业务”配置项启用六项专用模型能力：当前配置、联系人、问题、知识预览、本人确认、报告。它们复用同一业务服务与授权；权限来自可信入口与实时平台角色，不能由文本自报。维护许可独立于查询绑定；接口参数遗漏不能冒充权限拒绝。

报告支持文本与 HTML／Markdown／CSV 文件。文件通过官方预签名地址直接上传，按返回的内容类型、处置头和精确长度上传；Bot Token 不发给存储站点。生成前、上传前后及发送前检查范围。联系人原生实体不加入通知 UID 列表，不主动通知负责人。

## 接收和授权

Wukong v4 WebSocket 提供认证的消息入口；禁止不签名的 HTTP 入站后门。官方用户／群／子区和绑定在准入、排队执行与业务工具调用时复核。普通 Bot 默认忽略；管理员 Bot 必须有可验证平台身份，测试维护许可由管理员显式配置且仅限获准资产。

收件表记录已受理消息及最终待发送回复，重启或发送重试不重新执行业务；业务登记、预览及确认另有幂等保护。权限撤销阻止旧内容继续发送。配置保存的“启用”表示运行配置，不代表第一条平台消息已经投递；启用或轮换后需等待连接建立。平台尚未投递的离线消息不在本地账本保证范围内。

默认完整回复，不把中间推理、工具结果发进群。闲聊静默是正常完成。未发布资料、其他用户私聊和跨区域反馈不能通过猜 ID 读取。模型工具不提供浏览器、任意 MCP、宿主 shell 或跨会话记忆。

## 存储与验收

原生会话表按渠道、区域及用户隔离；PostgreSQL 99–103／SQLite 20–24 增加目录授权、知识业务与消息账本。删除回退可能丢失新业务记录，正式升级保留恢复材料，不直接执行有损 down。

运行渠道、权限、身份、业务、模型 ID 映射、迁移和前端测试；真实验收覆盖群问答、维护确认、问题、报告与投递。机器人私聊若受好友关系限制，不冒充真人 UID。

卡片不是必需入口；尚未开放的交互回调不由模型自行调用。源码读取、检索和文件解析复用 WeKnora 原生服务，来源目录不是执行工作区。当前官方域名策略不自动接受任意自托管地址。
