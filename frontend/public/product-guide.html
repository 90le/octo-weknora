业问进入产品

关于业问

业问是秒针面向业务团队提供的企业知识问答产品。你可以用日常语言提问，在有权访问的知识库中查找资料，并通过引用核对答案。

知识问答账号与权限管理与接入开源软件声明

提问与核对引用

在知识库查看已完成解析的文档。从聊天页选择有权使用的知识库，输入业务问题。打开回答中的引用即可核对对应文档片段。没有找到依据时，可以缩小问题范围或补充资料。

账号与工作区

使用工作区提供的入口登录。首次使用或需要访问其他知识库时，请联系工作区管理员获取邀请或授权。

模型设置

管理员可在设置的模型管理中配置对话、向量和重排序模型。按服务商提供的模型名、服务地址和鉴权方式填写，并测试连接。

模型协议兼容

在模型编辑页选择与服务端一致的协议。遇到不支持的请求字段时，请核对服务商的接口说明，再调整对应的兼容选项。

知识图谱

在知识库设置中配置实体和关系的提取范围。完成解析后，可从文档及相关实体查看关联材料。

消息渠道

在集成设置中选择渠道，按渠道要求配置机器人凭证、可访问的知识库和会话范围。先用测试会话核对身份和回答引用。

API 接入

从集成设置的 API 信息中复制当前服务地址，使用具备相应知识库权限的凭证。网页嵌入请复制渠道生成的脚本，并将宿主网站加入该渠道的允许列表。

命令行接入

从产品源代码包根目录进入 cli 构建客户端，或使用管理员提供的可执行文件。在集成页复制连接命令。运行 weknora --help 查看命令，运行 weknora doctor 检查连接。

沙箱执行环境

在设置中选择已部署的沙箱后端并测试连接。执行代码、访问网络和文件的范围由管理员配置的权限决定。

数据库迁移提示

系统信息显示迁移异常时，将页面中的版本和错误信息交给本部署的管理员。恢复或重新执行迁移前，应核对数据库备份和目标版本。
